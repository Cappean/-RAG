# 医疗智能问诊前端验收说明

## 验收范围

- 桌面端单页工作台，使用 Vue 3、Vite、TypeScript 和 Lucide 图标。
- 页面布局、颜色、信息层级和主要文案按提供的参考图实现。
- 前端默认由 mock API 提供；可通过环境变量切换至 FastAPI server API。接口协议见《医疗智能问诊前端接口指南.md》。
- 页面是交互原型，不是已连接真实患者数据库、知识库或模型的医疗服务。

## 本地运行

```powershell
npm install
npm run dev
```

打开终端输出的本地地址。本次验收运行于：

```text
http://localhost:5174/
```

若端口被占用，Vite 会自动选择其他端口。

默认使用 mock 数据。接入 FastAPI 时，在项目根目录创建 `.env.local`：

```env
VITE_API_MODE=server
VITE_API_BASE_URL=http://localhost:8000
```

修改环境变量后需重启 Vite。不要将 DeepSeek 密钥放入 `VITE_` 前缀变量，此类变量会打包到浏览器。

## 文件说明

- `src/App.vue`：页面结构和交互状态。
- `src/style.css`：桌面端样式。
- `src/api/mockApi.ts`：页面模拟数据及未来 API 接入位置。
- `src/api/serverApi.ts`：FastAPI REST 与 SSE 请求适配。
- `src/api/index.ts`：按 `VITE_API_MODE` 选择 mock 或 server。
- `医疗智能问诊前端接口指南.md`：REST、SSE、上传和来源定位字段约定。

## 当前边界

- 文档查看层用示例页面模拟 PDF 定位，不读取真实 PDF。实际接入需用 PDF.js 或其他阅读器加载后端授权返回的短时文件地址，并按 `pageIndex` 跳页。
- Markdown 文档的标题锚点定位协议已在接口指南中定义，页面阅读器待接入。
- 文件选择当前仅在前端显示文件名；知识库 PDF/Markdown 上传接口已在指南中定义，报告附件上传尚未接入。
- 问诊内容、引用、延迟和历史会话均为演示数据；不可用于真实医疗判断。
- 页面仅按桌面宽度设计，窄屏移动端不在本次验收范围内。

## 后端联调入口
